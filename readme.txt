SMCP MUN final fixed static website

Built with simple HTML, CSS, JavaScript, and Bootstrap CDN.
All main pages are separate: Home, Committees, Conferences, Team, About, Contact.
Team page includes clickable department decks and grayscale-to-color hover for member photos.

How to View Website UI:
- Run start-website.bat OR open index.html directly in your browser.
- Live local server preview: http://localhost:8000
